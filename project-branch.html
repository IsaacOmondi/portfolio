Fintech Compliance & Security

Backend Engineer at Branch International

Sep 2023 - Dec 2024 · Nairobi, Kenya

Overview

Branch International is a fintech lending platform operating across emerging markets, primarily in India, Kenya, Nigeria & Tanzania. The platform connects lenders with borrowers in underserved communities. During my 1+ years there, I built critical compliance and fraud detection infrastructure that powered the platform's expansion and enabled responsible lending at scale.

My focus was on regulatory compliance, user security, and automated systems that reduced manual work while maintaining strict controls required in fintech.

The Challenge

  • ▪ Regulatory complexity: Multiple jurisdictions with different compliance requirements for lending and KYC
  • ▪ Fraud prevention: High-volume lending platform required automated fraud detection without slowing down loan approvals
  • ▪ Manual bottleneck: Loan review process was heavily manual, limiting throughput and scalability
  • ▪ User security: Needed systems to identify and block sanctioned or fraudulent actors without impacting legitimate users

The Solution

1. Automated Compliance Check System

Built an automated compliance verification system that checks borrower data against regulatory databases and sanctions lists. This system runs as part of the loan disbursement pipeline, eliminating manual review steps.

Impact: Reduced manual intervention by 40%, accelerated loan processing

2. Multi-Country Verification Service

Engineered a verification service that identifies sanctioned users across multiple countries. The system aggregates data from various regulatory sources and flags high-risk borrowers before they can access the platform.

Impact: Enhanced system integrity, minimized fraud risk exposure

3. Facial Recognition for Fraud Detection

Implemented facial recognition technology to detect identity fraud. Integrated with the KYC process to verify that the person completing the loan application matches their submitted ID.

Impact: Reduced fraudulent access, increased user confidence in platform security

4. KYC Optimization & Data Analytics

Worked with the Sisense analytics platform to monitor KYC workflows and product launch performance. Used data-driven insights to optimize the verification process and identify bottlenecks.

Impact: Improved decision-making, enabled rapid iteration on compliance workflows

5. Real-time Risk Assessment

Built real-time risk scoring systems that assess borrower risk profile during application. The system balances fraud prevention with user experience, allowing legitimate borrowers to proceed quickly.

Impact: Faster approvals for good borrowers, improved conversion rates
