Healthcare Microservices

Full Stack Developer at XelphaHealth

May 2018 - Mar 2019 · Nairobi, Kenya

Overview

XelphaHealth is a healthcare technology platform providing telemedicine and health management services. During my time there, I worked on refactoring the backend microservices architecture to improve code quality and system performance. This was my first major role focusing on full stack development, where I gained deep experience with both frontend and backend optimization.

The project centered on eliminating technical debt, optimizing database queries, and ensuring the platform could handle production load with reliability.

The Challenge

  • ▪ Code duplication: Multiple microservices had replicated business logic, making maintenance difficult
  • ▪ Query performance: N+1 queries and inefficient joins were causing slow API response times
  • ▪ Production readiness: System hadn't been load tested; unknown how it would perform under real usage
  • ▪ Technical debt: Legacy patterns and inconsistent architecture made onboarding new developers challenging

The Solution

1. Microservices Refactoring

Systematically reviewed and refactored each microservice to eliminate redundant code. Extracted common patterns into shared libraries and standardized communication between services.

Impact: Eliminated 20% of codebase, reduced maintenance surface area

2. SQL Query Optimization

Analyzed database query patterns using explain plans and query profiling. Identified N+1 problems, unnecessary joins, and missing indexes. Rewrote critical queries for efficiency.

Impact: Improved query performance, reduced database load

3. Load Testing & Stress Testing

Conducted comprehensive load testing to identify bottlenecks and failure points. Simulated production traffic patterns and measured system behavior under stress. Identified and fixed scaling issues before they impacted real users.

Impact: Verified production readiness, prevented outages

4. Application Performance Monitoring

Implemented monitoring and logging to track API performance in production. Set up alerts for slow queries and error rates. Created dashboards for real-time system visibility.

Impact: Better visibility into system health and performance

5. Caching Strategy

Designed and implemented caching layers at multiple levels: HTTP caching, database result caching with Redis, and application-level caching for frequently accessed data.

Impact: Reduced database queries, faster response times

Key Learnings

  • ▪ Performance is a feature: Slow systems feel broken; optimization isn't optional, it's part of the user experience
  • ▪ Load test before production: You can't guess how systems will perform; testing is essential to prevent outages
  • ▪ Monitoring enables action: Visibility into system behavior is prerequisite for effective optimization
  • ▪ Technical debt compounds: Small quality issues accumulate; addressing them early is much cheaper than major refactors
